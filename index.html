Garage Session

User manual

Start a workout
Tap a workout name on the home screen. Sets appear one at a time. Adjust weight with +5 / −5, enter reps, confirm.

Live edits during a set
The exercise name is editable. Change it before confirming if you switch lifts. Use Switch exercise to reorder remaining exercises. Use Edit log to fix earlier sets. End workout returns home and clears the active session.

Progression
When every set of an exercise reaches 12 reps, the next suggested weight increases by 5 lb.

Daily log
Optional body weight and steps on the home screen. Charts and history live under Progress and Log.

Edit workouts
Rename workouts, reorder/add/delete exercises, add or delete whole workouts. Changes apply to new sessions.

Backup
Data stays on this device. Use Backup log now or Save log as CSV to export. Import restores from a previous CSV.
